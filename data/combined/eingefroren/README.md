# Eingefrorene Datensätze

Hier liegt je Gruppe ein Ordner mit dem festen Stand für das Semester. Den Namen Deines Ordners findest Du in der Tabelle „Deine Lehrperson“ auf der Übersichtsseite von Sitzung 01.

- `m15-gesamt.csv`: der Gesamtdatensatz, mit dem Du ab Sitzung 02 rechnest
- `meta-studien.csv`: die Tabelle für die Metaanalyse in Sitzung 04
- `merge-report.md`, `pruefbericht.md`: was beim Zusammenführen und Prüfen passiert ist

Ein Ordner erscheint hier, sobald der Stand Deiner Gruppe eingefroren ist.
