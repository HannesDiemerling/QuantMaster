# Uploads (hier hochladen)

Lade hier Deine bereinigte Datei hoch: **`datensatz-XX-<Kennziffer>.csv`**, zum Beispiel `datensatz-07-234567.csv`.

- Immer mit Deiner Kennziffer im Namen, sonst kannst Du die Datei einer anderen Person überschreiben.
- Korrigierte Fassung? Unter **demselben** Namen wie hier im Ordner erneut hochladen.
- Ob alles geklappt hat, siehst Du im [Merge-Report](../combined/merge-report.md), sobald der Workflow durchgelaufen ist.
