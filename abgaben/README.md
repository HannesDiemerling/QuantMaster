# Abgaben

Hier liegen die Abgaben aller Gruppen, je Sitzung eine Textdatei pro Person. Öffne den Ordner Deiner Gruppe. Den Namen findest Du in der Tabelle „Deine Lehrperson“ auf der Übersichtsseite von Sitzung 01.

| Gruppe | Ordner |
|---|---|
| frederike | [abgaben/frederike](./frederike/) |
| hannes | [abgaben/hannes](./hannes/) |

Lege nur Deine eigene Datei an, also `<Deine Kennziffer>.txt` im Ordner Deiner Gruppe und Sitzung. Dateien anderer Personen bleiben unberührt. Rückmeldungen und Übersichten erzeugt das Repo automatisch, ändern musst Du dort nichts.
