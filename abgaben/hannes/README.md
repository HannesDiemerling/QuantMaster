# Abgaben der Gruppe hannes

Für jede Sitzung gibt es einen eigenen Ordner. Der Link öffnet eine neue Datei mit der fertigen Vorlage. Nenne sie `<Deine Kennziffer>.txt`, trag hinter jeder Frage Deine Antwort ein und klicke auf *Commit changes*.

Zum Korrigieren öffnest Du Deine Datei im Ordner, klickst oben rechts auf das Stift-Symbol, änderst die Werte und klickst auf *Commit changes*.

Ohne GitHub-Account schickst Du denselben Text per Mail an Deine Lehrperson, Betreff `M15 Abgabe SNN <Kennziffer>` mit der Nummer der Sitzung statt NN. Sie stellt die Datei für Dich ein. Deine Rückmeldung siehst Du ohne Anmeldung im Browser neben Deiner Datei im Ordner Deiner Gruppe und Sitzung. Für eine Korrektur schickst Du eine neue Mail.
